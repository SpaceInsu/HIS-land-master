# 이 집 얼마? (HIS-land-master)

수도권(서울·경기·인천) 지도 위 집의 실거래가를 맞히는 웹 게임입니다.

- 게임: https://spaceinsu.github.io/HIS-land-master/
- 계획서: [PLAN.md](PLAN.md)
- 현재는 **샘플(추정) 가격** 12개로 동작합니다. 국토부 실거래가 연동은 다음 단계입니다.
- 카카오맵/로드뷰: `index.html` 맨 위 `KAKAO_JS_KEY`에 카카오 JavaScript 키를 넣으면 켜집니다. (키는 카카오 앱 설정에 등록한 도메인에서만 동작)
