# 문제집 데이터 형식 (data/questions.json)

게임은 이 파일이 있으면 샘플 대신 이 데이터를 씁니다. 5개 미만이거나 파일이 없으면 샘플로 동작합니다.

```json
{
  "source": "KB시세",
  "updated": "2026-11-27",
  "items": [
    { "name": "단지명", "region": "서울 송파구 잠실동", "area": 84, "floor": 15,
      "built": 2008, "ym": "2026-11", "price": 260000, "lat": 37.5115, "lng": 127.0815 }
  ]
}
```

- price: 만원 단위 (1억 = 10000). 1억~50억 범위만 출제
- area: 전용면적(㎡), floor: 층(시세 데이터면 생략 가능, 0이면 "-"로 표시 예정), ym: 기준 연월
- 데이터 수집 스크립트는 출처(KB/국토부)가 정해지면 `scripts/`에 추가
